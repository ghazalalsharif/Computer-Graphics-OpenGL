# Computer Graphics with OpenGL

Academic graphics exercises collected by Ghazal ALsharif using C++, OpenGL and GLUT.

## Examples

| Source file | Demonstration |
| --- | --- |
| robot-transformations.cpp | A robot assembled from geometric primitives; arrow-key movement, R rotation, and + / - scaling |
| scene-drawing.cpp | A 2D scene with a river, boat, sun and tree |
| keyboard-transformations.cpp | WASD movement, scaling, rotation and F1–F3 color changes |
| star-colors.cpp | A star made of triangles with number-key color controls |
| triangle-fan.cpp | An eight-triangle pattern with several color arrangements |

## Build and run

Compile each source separately: each example has its own `main` function. A C++ compiler and OpenGL/GLUT development libraries are required. Configure your compiler's include and linker paths for your platform. Windows-style GLUT include paths may need adjustment on other platforms.

These are coursework examples using legacy immediate-mode OpenGL. They have been reviewed as source files but not rebuilt as part of repository preparation. Scaling is not clamped in all examples.
